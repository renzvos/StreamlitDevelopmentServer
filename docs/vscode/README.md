# VSCode Integration Guide

This project integrates VSCode Tasks with the CLI so you can control the dev
machine without leaving the editor.

## Prerequisites

1. Complete onboarding first:
   - `python main.py onboard`
2. Open this project root in VSCode:
   - `/home/runner/work/StreamlitDevelopmentServer/StreamlitDevelopmentServer`

## Available tasks

Run from `Ctrl+Shift+P` → `Tasks: Run Task`:

- `Streamlit: Start`
- `Streamlit: Stop`
- `Streamlit: Restart`
- `Streamlit: Attach (live logs)`
- `Dev Machine: Start All`
- `Dev Machine: Stop All`
- `Dev Machine: Status`

`Streamlit: Start` is the default build task and is bound to `Ctrl+Shift+B`.

## Important behavior

- `.vscode/tasks.json` is auto-generated by `sds/setup/vscode_setup.py`.
- Manual edits to tasks may be overwritten when onboarding/setup runs again.
- If commands fail with missing dependencies, run:
  - `python -m pip install -r requirements.txt`
